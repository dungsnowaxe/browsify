# Browsify logo redesign

Open `comparison.svg` for the three directions and actual 64, 32, and 16 px previews.

1. **Route B (recommended):** a solid stencil B. The horizontal split and two counters suggest separate destinations without drawing a routing diagram. Warm vermilion tile; off-white mark.
2. **Switch:** a single incoming path that turns toward two destinations. Deep green tile; off-white mark.
3. **Open tabs:** a B assembled from window-like forms with an offset tab. Periwinkle tile; off-white mark.

Each direction includes a standalone SVG app icon and a black, transparent monochrome SVG. Monochrome assets are design sources, not installed macOS template images. The comparison sheet embeds all artwork and needs no external files, fonts, or network requests.

Route B was selected. The canonical source is now `../browsify-logo.svg`; the UI assets and bundled macOS app icon use that direction. Original concepts remain here for comparison.

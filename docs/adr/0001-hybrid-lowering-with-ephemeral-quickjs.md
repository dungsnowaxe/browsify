# Compile-Time Hybrid Lowering with Ephemeral QuickJS

Browsify evaluates `.js` and `.ts` configurations using an embedded QuickJS-ng (`rquickjs`) runtime, lowers declarative rules and built-in `finicky.*` helper markers into native Rust `browsify-core` matchers and transforms at load time, and drops the QuickJS VM immediately whenever no dynamic JS callbacks remain. When a configuration contains custom JS closures, Browsify executes an ordered hybrid pipeline that runs static steps in native Rust and enters QuickJS only for the dynamic steps, binding OS queries (`getModifierKeys`, `getPowerInfo`, `getSystemInfo`, `isAppRunning`) as lazy Rust host functions. We chose this over macOS's built-in `JavaScriptCore` (which holds ~15.5 MB RSS permanently and prevents Linux compilation/testing) and Finicky's Goja+Babel pipeline (~165 MB RSS peak), achieving ~4.5 MB RSS (`0 KB` JS heap) for static configs and ~5.1 MB RSS (`~550 KB` dirty anon RAM) for dynamic JS configs.
